② 案例第一题三件套：质量属性+六要素+风格 ⏱12'四年真题全中·必考

质量属性判据速查（看到这些词→选那个属性）

属性判据关键词
性能吞吐量/响应时间/延迟/QPS/「X 秒内完成」
可用性故障/宕机/失效后「X 分钟内恢复/切换/重构」
安全性未授权/伪造/攻击/阻断/身份认证/保密
可修改性「修改 X 只需 ≤N 人天/不改其他模块」/变更成本
可测试性「X 分钟内完成测试/输出测试报告」
可维护性政策/环境变化→修改功能（外部驱动的长期维护）
可伸缩性「10万→100万只需加节点/分区不改代码」
功能性「四项操作必须全部成功完成」（做什么）
可变性「在现有架构上演进/不允许推翻重写」
互操作性对接外部系统/标准协议(OCPP)/JSON 映射

易混点：修改业务功能=可修改性；政策法规强制改=可维护性；容量增长加机器=可伸缩性；架构演进不重写=可变性。

六要素（口诀：源激环制响度）

刺激源→刺激→环境(设计时/运行时)→制品→响应→响应度量。例：用户(源)要换算法(激)在设计时(环)对算法模块(制)替换插件不改他模块(响)≤4人天(度)。

架构风格选型（近年真题问法）

场景选理由关键词
数据流式处理/逐级加工(入侵检测)管道-过滤器（优于批处理：边到边处理、低延迟、可并行）流式、增量处理、松耦合
解释执行脚本/自定义语言(模型训练平台)解释器（伪程序+解释引擎+两个当前状态记录）灵活性、自定义规则
事件触发多流程/异步通知(电池监测)事件驱动（优于分层：异步解耦高吞吐）发布订阅、扇出
传感器汇聚+中心数据+多知识源仓库/黑板（中央数据结构说明当前状态）知识源独立、 opportunistically

ATAM 一行记

效用树两维度=重要性×实现难度（各高中低）；场景三类型=用例/增长(容量扩充)/探测(超出预期的极端修改)。口诀见第⑧块。

③ Redis 速览 ⏱12'五年全考·必选做

五年考点一句话（子专题轮换）

24上=分布式锁死锁场景+zset 指令(zadd/zrange/zscore) → 24下=旁路缓存读5步写2步 → 25上=主从+持久化 → 25下=击穿两方案 → 26上=悲观/乐观锁。

击穿两方案（2025-11 原题）

  • 互斥锁：抢锁→查库重建→写缓存→释放；他人等待重查。优=强一致；缺=锁竞争延迟。
  • 逻辑过期：不设物理 TTL，加逻辑过期字段；过期后立即返回旧数据+异步重建。优=高吞吐；缺=弱一致。
  • 五维对比：复杂度(锁简单)/一致性(锁强)/性能(逻辑过期高)/内存(逻辑过期多存)/场景(锁=库存扣减，逻辑过期=详情页)。

主从复制（2025-05 原题）

  • 全量 7 步：从 PSYNC ? -1 → 主 BGSAVE 生成 RDB → 发 RDB → 从清空加载 → 主补发期间写命令 → 从执行。
  • 增量：从带 replid+offset PSYNC → 缺失在 repl_baklog 内 → CONTINUE 从 offset 续传。
  • RDB=快照二进制，文件小恢复快；AOF=追加日志，丢失少可读性强；AOF 重写瘦身。生产 RDB+AOF 混合。

旁路缓存 Cache-Aside（2024-11 原题）

读：查缓存→命中返回/未命中查库→写回缓存(设TTL)→返回。写：先更新数据库，再删除缓存。多线程不一致=写慢读快窗口，解法：延迟双删/设置较短 TTL/分布式锁/读写串行化。

首考候选（从未考，今年增量概率大）

  • 哨兵转移：主观下线(单哨兵)→客观下线(≥quorum)→竞选领头(过半)→选新主(过滤→priority→offset 最大→runid 最小)→其他从库改 replicaof→旧主降从。
  • 雪崩：大面积同时失效；三层=TTL 加随机值/热点不过期或逻辑过期 + 集群高可用 + 多级缓存限流降级。
  • 事务：MULTI/EXEC/DISCARD/WATCH；入队错=整体放弃，运行时错=其余照跑不回滚；WATCH=CAS 乐观锁。
  • 热 Key=本地缓存/副本打散/读写分离；大 Key=拆分/压缩/UNLINK 异步删。
  • Cluster：16384 槽 CRC16(key)；MOVED/ASK 重定向；gossip 传播；主挂由半数以上主节点判定、从库补选。

布隆/穿透/淘汰（押题）

布隆：任一位 0→一定不存在直接返回；误判率可<1%。穿透=查不存在的 key→布隆/空值缓存。淘汰 8 种：noeviction + volatile-{lru,lfu,ttl,random} + allkeys-{lru,lfu,random}。

④ UML 与结构化（DFD/ER） ⏱8'高频槽位·近年未出

类分三类（口诀：界面是边界、业务是控制、数据是实体）

边界类=系统与外界交互（界面/APP）；控制类=业务逻辑协调（控制器/服务/消息队列）；实体类=持久信息（患者/医生/订单）。

用例图

  • include=必发生的子流程（包含方→被包含方）；extend=可选/条件分支（扩展方→被扩展方，箭头指向基础用例）。
  • 参与者=系统外的人/系统；识别：谁用系统/谁维护/与哪些外部系统交互。

DFD 四件套与三大检查

  • 要素：外部实体(方框)/加工(圆/圆角框)/数据存储(双横线)/数据流(箭头)。
  • 检查：父图子图平衡（输入输出一致）；加工三错=黑洞(只有入)/奇迹(只有出)/灰洞(入不足以产出出)。
  • 结构化语言写加工逻辑：顺序+IF/ELSE 选择+WHILE 循环，变量取自说明原文。

类图关系强弱

泛化(继承)＝实现 > 组合(同生命周期) > 聚合(可分离) > 关联 > 依赖。顺序图=时间序消息；状态图=事件驱动迁移；活动图=流程+并行。

⑤ 综合高频·架构主线（真题 25+19+19 次） ⏱8'

架构风格分类树（25 次考点的骨架）

  • 数据流：批处理（完整输入顺序处理）/管道-过滤器（流式，过滤器可并行）
  • 调用/返回：主子程序/面向对象/层次/客户端-服务器（B/S=特殊三层 C/S）
  • 独立构件：进程通信（连接件=消息传递）/事件系统（隐式调用）
  • 虚拟机：解释器（被解释代码+解释引擎+两个状态记录）/规则系统
  • 以数据为中心：仓库（中央数据结构+独立构件）/黑板（知识源+黑板+控制）

质量属性子特性（选择题爱考「不属于」）

可靠性=成熟性+容错性+易恢复性（稳定性不属于）。安全性=保密性+完整性+不可否认性+可控性。可维护性=易分析+易改变+稳定+易测试+维护符合性。

架构评估三法

  • SAAM：最初非功能质量场景法（敏感性/权衡点）。
  • ATAM：效用树+场景三类型+九步（口诀第⑧块）。
  • CBAM=成本效益；基于度量=质量属性↔度量映射推导属性值。

4+1 视图（7 次）

逻辑视图(功能/类)/进程视图(并发同步)/开发视图(模块组织)/物理视图(部署映射)/场景视图(串联其余四个)。Hofmeister 4 视图=概念/模块/执行/代码（无「逻辑视图」）。

ABSD 与 DSSA（12+11 次）

  • ABSD 三基础=功能分解+选择架构风格+软件模板（不含项目管理）。演化六步：需求变化归类→订计划→改构件→更新构件相互作用→组装测试→技术评审。
  • DSSA 三角色=领域专家/领域分析人员/领域实现人员；建立过程五阶段（并行递归反复，不是原型模型）。

构件/CBSE（9 次）

构件=独立部署+第三方组装+无状态对外可见。组装三方式=顺序/层次/叠加组装。

⑥ 综合高频·开发/数据库/系统 ⏱8'

开发模型（12 次）

  • 瀑布=需求明确；增量=分批交付；螺旋=风险驱动(每圈风险分析)；喷泉=面向对象迭代；V 模型=测试左移对应。
  • RUP 四阶段：初始(愿景)→细化(核心架构+计划，设计计划集中在此)→构建→移交。统一过程以用例驱动+架构为中心+迭代增量。
  • 敏捷宣言四对：个体交互>过程工具；可运行软件>详尽文档；客户合作>合同谈判；响应变化>遵循计划。Scrum 每日构建后的自动验证测试=冒烟测试。

设计模式与设计原则（10 次）

  • 一句话模式：命令=封装请求可撤销排队；备忘录=存状态快照供恢复；观察者=一对多通知；适配器=接口转换；策略=算法族切换；单例=唯一实例。
  • 原则：依赖倒置=面向接口不依赖具体类；接口隔离=小接口；开闭=扩展开放修改关闭；最少知识=只谈直接朋友；迪米特=不要和陌生人说话。

数据库（9 次）

  • 范式判定链：存在部分函数依赖→只满足 1NF；消部分(码为整体函数依赖)→2NF；消传递→3NF；每个决定因素都含码→BCNF。主属性/非主属性分开判。
  • 三级模式：外模式(局部逻辑)=视图级、概念模式=全局逻辑、内模式=物理存储。两级映像保数据独立性。
  • 两段锁 2PL=先加后放、扩展+收缩；死锁四条件：互斥/保持等待/不剥夺/环路等待。悲观锁=SELECT…FOR UPDATE。

进程/嵌入式（11+9 次）

  • 五态：运行→就绪=时间片到/主动让出；运行→阻塞=等待事件(I/O/请求资源)；就绪→运行=调度。wait/P 操作可能阻塞。
  • RTOS：实时性高/资源小/启动毫秒级/但弱内存保护；Linux 反之。选型答「功能+实时+成本+功耗」四权衡。

知识产权（7 次）

署名权/修改权/保护完整权=无时间限制；发表权+财产权=作者终身+50 年。GB=强制标准，GB/T=推荐。GPL=强传染(衍生须开源)，LGPL=可被闭源动态链接。

⑦ 安全与数学速算 ⏱5'

密码学一句话

  • 对称(快、大批量)：AES>DES(已不安全)；非对称(慢、密钥分发)：RSA/ECC。混合=非对称传对称密钥。
  • 数字签名=私钥签名、公钥验证（防抵赖+完整性）；数字证书=CA 私钥签名的公钥信息。
  • IPsec：AH=认证+完整性(无加密)；ESP=加密+认证；IKE=协商密钥(SA)。IPsec 不能防 DDoS(不提供可用性)。
  • SSH=安全远程登录；HTTPS=HTTP+TLS(443)；对称加密不能防抵赖（双方同钥）。

可靠性公式（7 次）

  • MTBF = MTTF + MTTR（平均无故障=正常运行+修复）。可用度 A = MTTF/(MTTF+MTTR)。运行时间/故障数=平均间隔（注意是否扣修复时间）。
  • 串联可靠度相乘 R=R₁R₂…；并联 1-(1-R₁)(1-R₂)…。N 版本编程=相异成分规范评审+相异性确认+背对背测试。

存储/数学（8 次）

  • 位示图：容量÷页大小=页数；页数÷8=位示图字节数（16GB/4KB=4M 页→512KB 图）。
  • Dijkstra=单源最短路（逐步贪心扩展）；数据结构：n 节点无向完全图边=n(n-1)/2；二叉树 n₀=n₂+1。
  • 线性规划极点在凸多边形顶点/边界：判断选项是否落在两已知极点连线上(斜率/方程代入)。
⑧ 口诀与英语五连 ⏱4'

ATAM 九步口诀：法师购柿树，惜抱栽结果

法=ATAM方法表述 → 师(商)=商业动机 → 购(构)=架构表述 → 柿(识)=识别架构方法 → 树=生成质量属性效用树 → 惜(析)=分析架构方法 → 抱(暴)=头脑风暴定场景优先级 → 栽(再)=再次分析架构方法 → 果=结果表述。
陷阱：第 6 步「分析」与第 8 步「再次分析」仅差二字，选择题常挖这个坑。

高频口诀

  • 六要素：源激环制响度。
  • 类三分：界面边界、业务控制、数据实体。
  • DFD 三错：黑洞奇迹灰洞；父子图必须平衡。
  • 主从全量：PSYNC→BGSAVE→发RDB→补写命令。
  • 写缓存：先更库，后删缓存。

英语五连题词汇（近年主题：IT 与业务对齐）

词义

⑨ 最后一眼清单（进考场电梯里看这个） ⏱1'打印版压轴
  • 案例第一题=质量属性判据 + 源激环制响度 + 风格选型三件套。
