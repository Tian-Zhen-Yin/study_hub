  • 🧠 交互式考点知识图谱与记忆熔炉
⭐ 前往 GitHub 获取完整源码
# 方式一：单 Jar 零依赖启动（内置 H2 数据库）
git clone https://github.com/Tian-Zhen-Yin/study_hub.git
cd study_hub && ./scripts/start.sh

# 方式二：Docker Compose 一键部署（含 MySQL 8）
cp .env.example .env
docker compose up -d

# 访问 http://localhost:8080 开始备考！
